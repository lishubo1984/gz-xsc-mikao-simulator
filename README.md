# 广州小升初密考模拟系统

广州小升初（民校密考 / 联考）数学模拟卷**自动化生成** Web 应用。归纳广州近八年几所初中密考的知识点形成"知识链"，点击出卷即按知识点分类自动出题；题目答案由代码**实时计算**，杜绝任何模型算术幻觉。

## ✨ 特性

- **参数化题库**：每道题是一个带公式的模板，答案由 `answer_expr` 在 Python 里算出来，不依赖任何生成式模型。
- **分层质量门禁**：静态 Lint + 动态审计 + 八层体检链，出卷不通过宁可报错也不交付有问题的卷。
- **卷面规格**：100 分钟 / 100 分 / 38 题，六大模块按目标分值占比配额出卷。
- **一键启停**：`start.bat` 双击启动并自动打开浏览器，`stop.bat` 按端口精确停止服务。
- **答题 + 答案页**：网页答题、判分；导出 PDF 打印版（学生作答卷 + 答案思路页）。

## 🧱 技术栈

Python 3.13 · FastAPI · SQLAlchemy（SQLite）· 原生前端（HTML / CSS / JS）。

## 🚀 本地运行

**方式一（推荐，Windows 双击）**

- 双击 `start.bat` 启动服务并自动打开浏览器；
- 双击 `stop.bat` 按端口（8765）精确停止。

**方式二（命令行）**

```bash
pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8765
```

浏览器访问 <http://127.0.0.1:8765> 。

> PDF 导出依赖 Playwright，首次需执行 `playwright install chromium`。

## 📁 目录结构

| 路径 | 说明 |
| --- | --- |
| `app/` | 应用源码（api / services / web 三层） |
| `data/bank/*.jsonc` | 参数化题库（JSONC，支持 `//` 注释），含 W5 扩充库 |
| `data/knowledge_graph.yaml` | 知识图谱与卷面格局（模块占比、知识点、配额） |
| `scripts/` | 题库 Lint / 审计 / 冒烟 / 端到端测试工具 |
| `start.bat` / `stop.bat` | 一键启停脚本 |

## ⚠️ 重要声明（诚实）

本仓库的题目是依据公开教研分析**重建的知识点骨架 + 原创仿真题**，用于学习训练，**不是广州任何一年的密考真题原卷**。
